🛒 E-Commerce Management System - GLAMAURA

📌 Overview

This project is a mini E-Commerce backend system that combines DBMS concepts with practical application development using Java and SQLite.

Unlike a purely theoretical database project, this system is designed with a real-world mindset, focusing on:
Scalable architecture
Clean backend logic
Efficient database design

🎯 Objectives
Build a structured backend for an e-commerce platform
Apply database normalization (1NF, 2NF, 3NF)
Implement functional dependencies & relationships
Integrate database with a Java-based application

🧱 Core Modules
👤 User Management
Stores user details securely
Unique identification using user_id
Supports authentication-ready structure (Firebase UID)
📍 Address Management
Allows multiple addresses per user
Maintains proper relational mapping using foreign keys
🛍️ Product Management
Stores product details like name, price, category, and stock
Designed for easy scalability and catalog expansion
Supports future features like search and filtering
🛒 Cart System
Allows users to add/remove products to cart
Maintains user-specific cart data
Acts as a bridge between product selection and order placement
💳 Payment (Design Level)
Structured to support card/payment handling
Designed with real-world extensibility in mind
🔗 Database Design Highlights
Proper use of Primary Keys & Foreign Keys
Maintains referential integrity
Eliminates redundancy using normalization
Designed for efficient querying and scalability


🧠 Concepts Applied
Functional Dependencies
Normal Forms (1NF, 2NF, 3NF)
Relational Schema Design
Data Integrity Constraints


⚙️ Tech Stack
HTML,CSS,JavaScript - Frontend
Python, Flask – Backend logic
MySQL – Database
Json – Connectivity
Firebase - Authentication

🚀 Future Enhancements
